# Program 17 – Insert Student Using Procedure

## Aim

Write a MySQL stored procedure to insert a student record into the Student table.

## Student Table

The Student table contains:

- StudentID
- StudentName
- DepartmentID

## Requirement

Create a procedure named:

InsertStudent

The procedure must accept:

- Student ID
- Student Name
- Department ID

and insert the record into the Student table.

## Concept

- CREATE PROCEDURE
- IN parameters
- INSERT statement
- Stored procedure
