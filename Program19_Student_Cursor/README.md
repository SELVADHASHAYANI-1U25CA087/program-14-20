# Program 19 – Student Cursor

## Aim

Create a cursor to fetch StudentID, StudentName and DepartmentID from the Student table and display the records.

## Requirement

Create a procedure named:

DisplayStudents

The procedure must:

1. Declare a cursor.
2. Fetch StudentID.
3. Fetch StudentName.
4. Fetch DepartmentID.
5. Display the records.
6. Properly handle the end of the cursor.

## Concept

- Cursor
- DECLARE CURSOR
- FETCH
- CONTINUE HANDLER
- LOOP
