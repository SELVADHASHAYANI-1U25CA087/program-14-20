# Program 14 – Sum of Two Numbers

## Aim

Write a MySQL stored program to declare two variables and display the sum of two numbers.

## Concept

- Variables
- SET statement
- Stored procedure
- Arithmetic expression

## Requirement

Create a procedure named:

CalculateSum

The procedure must declare two variables, assign values to them, calculate their sum and display the result.

## Expected Example

If:

Number 1 = 10
Number 2 = 20

Expected Sum:

30

## Software

Use MySQL Workbench.

## Submission

Complete `solution.sql`.
