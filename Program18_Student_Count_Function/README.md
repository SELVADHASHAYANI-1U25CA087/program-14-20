# Program 18 – Student Count Function

## Aim

Write a MySQL function to count the number of students available in a particular department.

## Requirement

Create a function named:

CountStudentsByDepartment

The function must accept DepartmentID as an input parameter and return the number of students belonging to that department.

## Example

If DepartmentID = 1 has 4 students:

Expected result:

4

## Concept

- CREATE FUNCTION
- IN parameter
- COUNT()
- SELECT INTO
- RETURN
