# STARTUP Instructions

## Step 1 – Install MySQL

Install:

- MySQL Server 8.0
- MySQL Workbench

## Step 2 – Open MySQL Workbench

Open MySQL Workbench and connect to your MySQL server.

## Step 3 – Create the Database

Execute:

CREATE DATABASE IF NOT EXISTS CollegeDB;

USE CollegeDB;

## Step 4 – Execute Each Program

Open the `solution.sql` file from the required program folder.

Complete the SQL program.

Copy the completed SQL into MySQL Workbench.

Execute the program.

## Step 5 – Verify the Output

Check the result in the MySQL Workbench output area.

For procedures, functions, cursors and triggers, verify that the required database object has been created successfully.

## Step 6 – Save the Work

Save the completed `solution.sql` file.

## Step 7 – Push to GitHub

Commit and push the complete repository.

Example:

git add .
git commit -m "Completed RDBMS Lab Set 2 Programs 14-20"
git push
