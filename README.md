# RDBMS Lab Set 2 – MySQL Stored Programs

## Programs 14–20

This repository contains RDBMS laboratory programs based on MySQL stored programming concepts.

Students must complete Programs 14 to 20 using **MySQL Workbench**.

## Programs

| Program | Topic |
|---|---|
| 14 | Declare two variables and display their sum |
| 15 | IF–ELSE to check student pass/fail |
| 16 | LOOP to display numbers from 1 to 10 |
| 17 | Procedure to insert a student record |
| 18 | Function to count students in a department |
| 19 | Cursor to display student records |
| 20 | Trigger after inserting an employee |

## Software Required

- MySQL Server 8.0 or compatible version
- MySQL Workbench
- Git
- GitHub account


## Submission

Each program must be completed in its corresponding folder.

Do not change the folder names.

Do not change the required procedure, function, cursor, or trigger names unless instructed.

## GitHub Submission

Push the complete repository to your GitHub repository.

The GitHub Actions workflow will perform basic automated checks.
