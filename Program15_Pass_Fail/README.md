# Program 15 – Student Pass or Fail

## Aim

Write a MySQL stored program using an IF–ELSE statement to check whether a student has passed or failed based on marks.

## Requirement

Create a procedure named:

CheckResult

The procedure must accept student marks as an input parameter.

Use the following rule:

Marks >= 40 → PASS

Marks < 40 → FAIL

## Example

Marks = 75

Result:

PASS

Marks = 35

Result:

FAIL

## Concept

- IN parameter
- IF–ELSE
- Conditional statements
- Stored procedure
