# Test Case – Program 20

## Trigger

AfterEmployeeInsert

## Requirement

The trigger must execute automatically after a new Employee record is inserted.

## Test

INSERT INTO Employee
VALUES (1, 'Arun', 'Computer Science');

## Expected Behaviour

A corresponding record must automatically be created in Employee_Log.

The log should contain:

EmployeeID = 1

and a meaningful message indicating that the employee was inserted.

## Second Test

INSERT INTO Employee
VALUES (2, 'Priya', 'Commerce');

A second log record should automatically be created.

## Important

The log record must be generated by the trigger.

The user should not manually insert the log record.
